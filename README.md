# GoURLShortener
A URL shortener using Golang

This webpage works off of port 8080 at the current moment, but can be changed when necessary

It allows a person to enter the webpage, and add a new subdirectory of the webpage that will redirect to a webpage of their choice by filling out the two fields.

URL Shortcut: The subdirectory to access to redirect to the designated webpage

Shortcutted URL: The webpage to redirect to
